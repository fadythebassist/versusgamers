# Artwork sources

Full-size originals of the artwork Fodz chose, generated with Higgsfield (GPT Image 2.5) on 2026-10-20.
The site uses resized copies:

| Source | Used as |
|---|---|
| `higgsfield/logo-vs.png` | `public/favicon.ico`, `public/icon-*.png`, `public/apple-touch-icon.png` |
| `higgsfield/key-art.png` | background of `public/images/og-default.jpg` (social sharing image) |
| `higgsfield/cover-*.png` | `public/images/originals/<game>.webp` (game covers) |
| `higgsfield/bg-*.png` | `public/originals/<game>/assets/bg.webp` (in-game backgrounds) |

The header logo is drawn in CSS so it can follow each skin.
